# Tarjeta personal (90 x 50 mm, frente y dorso)

Servir el proyecto (`python3 -m http.server 8765`) y correr `node marketing/tarjeta/render.js`. Sale en `entrega/tarjeta/`:
- `tarjeta-imprenta-sangrado3mm.pdf`: para la imprenta (96 x 56 mm, 2 páginas: frente y dorso).
- `tarjeta-90x50.pdf`: tamaño final, para revisar o imprimir en casa.
- `tarjeta-frente.png` / `tarjeta-dorso.png`: vista previa a 600 dpi.
