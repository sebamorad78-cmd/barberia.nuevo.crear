# Flyer

- `flyer.html`: el diseño (A5). Textos y colores se editan acá.
  Variantes: `?bleed=1` (imprenta, +3 mm de sangrado) y `?social=1` (1080 x 1350 para redes).
- `captura-reserva.png`: captura real del sistema de turnos (paso "Elegí día y horario").
- `qr.svg`: lleva a https://paginas-profesionales-1212.netlify.app/ (regenerarlo si cambia la dirección).
- `render.js`: genera los archivos finales en `entrega/` (servir el proyecto en http://localhost:8765 y correr `node marketing/flyer/render.js`).
- Tipografías Fraunces y Manrope (licencia SIL Open Font License, ver `fonts/`).
